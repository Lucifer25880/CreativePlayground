# 产品概览

## 定位

Creative Playground 是一个面向前端开发者、创意设计师、AI 编程使用者和视觉效果爱好者的**交互式视觉实验室**。

用户在这里可以：浏览高级视觉效果、进入实验页实时操作效果、修改颜色/材质/光照/速度/角度等参数、组合多个效果、保存配置、基于实验二次创作、自动生成当前效果对应的 AI 编程提示词、管理提示词版本并沉淀为自己的作品。

## 核心循环

```
Explore → Experiment → Remix → Generate → Save
探索      操作实验       二次创作    生成提示词   保存作品
```

## 三个层次

### 1. 展示层 Showcase

让用户第一眼感受到视觉品质。包含高品质动态首页、视觉展厅、分类浏览、具有真实动态预览的实验卡片、实验详情。

### 2. 实验层 Playground

让视觉效果真正可被操作。包含 Live Playground（左右分栏：参数面板 + 实时画布）、统一参数系统（number/boolean/color/select/vector2/vector3/range 等）、多效果组合的基础能力。

### 3. 创作层 Creative Studio

将结果沉淀为可长期管理复用的作品。包含：

- **Remix Studio**：复制实验 → 修改参数 → 保存独立作品 → 版本管理。
- **Prompt Generator**：本地模板生成 4 种模式（完整重生成 / 基于当前配置 / 增强 / 指定方向修改）的结构化提示词。
- **Prompt Library**：搜索、分类、收藏、版本对比、Markdown 导出。
- **My Works**：作品新建 / 编辑 / 删除 / 复制 / 收藏 / 导入 / 导出 / 打开实验。

## 设计语言

深色创意科技风、高级暗色背景、低饱和辅助色、重点区域渐变、玻璃质感、细腻边框、高品质排版、精致微交互。桌面端为创作主环境，移动端保留浏览与基础操作。
