# 测试计划

## 功能测试

### 展示层
- [ ] 首页动态 Hero、精选实验、能力、流程、页脚正常。
- [ ] Explore 分类过滤、搜索、收藏过滤正常。
- [ ] 实验卡片动态预览加载、悬停/点击/收藏正常。
- [ ] 实验详情加载信息、Start / Remix / Generate Prompt 可用。

### 实验层
- [ ] 20 个实验均进入且渲染，无控制台报错。
- [ ] 参数变化实时反映到渲染。
- [ ] 预设 / 重置 / 随机 / 保存 / 恢复 / 对比 / 导入 / 导出正常。
- [ ] 刷新页面后已保存配置恢复。
- [ ] 参数不会串扰其他实验。

### 创作层
- [ ] Remix 创建不影响原始实验；保存版本 / 恢复版本正常。
- [ ] 作品保存、编辑、复制、收藏、删除、导入、导出、打开实验正常。
- [ ] Prompt 生成 4 种模式可用；编辑 / 复制 / Markdown 导出 / 保存正常。
- [ ] 重新生成创建新版本；版本差异对比与恢复正常。
- [ ] 提示词与作品 / 实验关联互通。

## 工程质量测试
- [ ] `npm run typecheck` 通过。
- [ ] `npm run build` 通过。
- [ ] 路由懒加载与实验按需加载生效。
- [ ] Three.js 场景卸载释放资源（反复进入退出无内存增长）。
- [ ] 响应式：1920 / 1440 / 1366 / 平板 / 手机。
- [ ] 低性能降级（质量等级、减少动态效果）。

## 数据可靠性测试
- [ ] localStorage 不可用时降级到内存。
- [ ] 配置 / 作品 / 提示词保存与读取正确。
- [ ] JSON 导入格式校验，错误提示友好。
- [ ] 删除作品 / 提示词 / 版本恢复失败场景处理。

## 回归清单
- [ ] 所有导航与按钮真实可用，无装饰性按钮。
- [ ] 空状态与异常处理完整。
